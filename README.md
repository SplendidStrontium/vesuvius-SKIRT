# vesuvius-SKIRT

SKIRT synthetic photometry of Romulus dwarf-galaxy zoom-ins. Earlier development (Perspective, Deciphering the Dwarfs, and the original Enterprise pipeline with full history and documentation) lives in [tal-shiar-SKIRT](https://github.com/SplendidStrontium/tal-shiar-SKIRT). Scripts here were carried over from that repo and modified.

## Layout

- `src/` — pipeline modules (particle extraction, photometry, SFH)
- `scripts/` — helpers
- `notebooks/` - Jupyter notebooks
- `configs/` — SKIRT `.ski` templates and run lists
- `notes/` — work diary
- `reference/` — other people's code
